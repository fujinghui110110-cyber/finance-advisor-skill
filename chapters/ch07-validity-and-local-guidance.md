# 第 7 章：效力、版本与地方口径

## 核心要点

财税制度回答必须同时回答“规则是什么”和“何时、何地、对谁有效”。没有效力判断的正确条文，也可能被错误地用于当前期间。

## 版本闸门

| 检查项 | 必须回答的问题 |
|---|---|
| 发布 | 文件由谁发布、何时发布、是否为正式文件？ |
| 施行 | 何时生效？是否已施行？ |
| 过渡 | 是否有首次执行、追溯、比较数据或衔接安排？ |
| 地域 | 全国适用还是地方试行/解读？ |
| 主体 | 一般企业、小企业、金融机构、保险公司、境外主体是否不同？ |
| 版本 | 是否存在修正、替代或新旧准则并行？ |

## 来源提醒

`90_已发布尚未施行`中的文件必须在回答中显式标为“尚未施行”。来源中的 2026 年版财务报表列报准则注明自 2027-01-01 施行，不能直接作为 2026 年已生效的列报要求。

上海税务热点问答属于地方解读，使用时要先确认纳税主体、业务发生地和问题时间是否匹配。

## 反模式

- 只看文件标题，不看施行条款。
- 把整理版 PDF 的排版日期当成法规生效日期。
- 用地方口径回答全国性问题而不标注地域。

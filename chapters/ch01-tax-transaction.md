# 第 1 章：税法与交易识别

## 核心要点

税务判断的第一步是识别交易和纳税主体，而不是直接套税率。先判断是否发生应税交易、发生地、交易对象、计税方法和优惠/不征税边界，再处理销项、进项、销售额、扣缴和申报。

## 覆盖来源

- `01_增值税及2026配套政策`：增值税法及实施条例。
- `02_所得税及税收征管`：企业所得税、个人所得税、股息红利和特定企业政策。
- `05_印花税`：印花税法、执行口径、改制重组、证券交易和离岸贸易政策。
- `17_关税`：原始目录下的小微企业、个体工商户和融资相关税费政策；以文件标题和正文为准，不按目录名推定税种。
- `07_税务机关解读及地方口径`：地方热点问答，必须核对地区。
- `90_已发布尚未施行`：未来规则，不能默认适用于当前期间。

## 判断步骤

1. 确定主体：公司、个人、个体工商户、境外单位/个人或扣缴义务人。
2. 确定事项：销售货物、服务、无形资产、不动产、金融商品、工资薪金、股息红利、资产处置或非交易性收款。
3. 判断范围：境内发生、视同交易、非应税事项、免税项目和地方适用性。
4. 判断计税方法：一般计税、简易计税、扣缴、代扣代缴或其他专门方法。
5. 核对销售额、税率/征收率、进项抵扣限制、凭证和申报期间。
6. 将会计收入/成本与税务销售额、计税基础分开说明。

## 重点规则

- 来源中的增值税法列示 13%、9%、6%税率及简易计税征收率；实际回答仍应按交易性质和当前有效版本核对。
- 混合税率事项要分别核算；未分别核算时可能触发从高适用的风险。
- 进项税额能否抵扣取决于计税项目、用途、损失和扣税凭证，不能仅凭“取得发票”判断。
- 企业所得税、个人所得税问题要区分纳税人身份、所得性质、支付环节、居民/非居民状态和扣缴责任。
- 视同销售必须先查现行增值税法和实施条例的交易类型、主体、用途与计税规则；酒店免费房、员工消费、会员赠送不能仅凭“免费”二字下结论。

## 虚拟财务员工输出格式

**事实** → **税种与主体** → **应税/非应税判断** → **计税和凭证** → **会计影响** → **来源与生效状态** → **待补事实**。

## 反模式

- 先报税率、后判断交易：容易把税率套错对象。
- 把免税、不征税、零税率和简易计税混为一谈：法律后果和申报口径不同。
- 用地方热点问答替代全国性法源：必须标注地域和适用前提。
